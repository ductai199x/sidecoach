# Audit, 2026-10-07 (0.1.84)

Tai asked for a full audit of the codebase: what is still raw or rough at the edges, features
that would improve the experience, and UI improvements. Six read-only auditors covered
vision and state, analysis/profile/llm, the coach, the desktop UI and API, voice/setup/tools,
and the Android app (Reconcile, Stories, Score, Annotator and Pipeline compared with the
Python function by function). Every finding cites the code, and the high ones were
reproduced by probe scripts. This is the list to choose from. Fixed items should be struck
through with the commit that fixed them; items Tai dropped for good are marked so (as of 0.1.88,
2026-10-09).

How to read it: **P1** = a player gets a wrong result or loses something; **P2** = a rough
edge a player meets; **P3** = code health. Paths are under `src/sidecoach/` unless they start
with `desktop/`, `android/` or `tools/`.
